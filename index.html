⚙️ Asociar Control a Decos

📺 Asociar Control a la TV

Detección Automática

🔴 Control Champion:
Presiona SETUP hasta que parpadee 2 veces, luego presiona 📺 TV y mantén presionado OK hasta que el TV se apague.
🟢 Control Curve:
Presiona SETUP hasta que el botón ⏻ TV (power) quede encendido, luego mantén presionado ⏻ TV (power) hasta que el TV se apague.

Asociar Control al STB (Deco)

STB Modelo Amino

🔴 Control Champion:
Presiona SETUP + ▲ ROJO al mismo tiempo.
🟢 Control Curve:
Presiona SETUP + FAVORITOS hasta que el botón TV quede fijo, luego ingresa el número 1.

STB Modelo Entone

🔴 Control Champion:
Presiona SETUP + ◆ AZUL al mismo tiempo.
🟢 Control Curve:
Presiona SETUP + FAVORITOS hasta que el botón TV quede fijo, luego ingresa el número 2.

STB Modelo Adb

🔴 Control Champion:
Presiona SETUP + MENÚ al mismo tiempo.
🟢 Control Curve:
Presiona SETUP + FAVORITOS hasta que el botón TV quede fijo, luego ingresa el número 5.

Acciones en OST para Mikrotik

  • 📶 WiFi: Permite habilitar o desactivar la interfaz wifi del mikrotik. Además de configurar el SSID Y Pass.
  • 📤 Enviar Firmware: Realiza la carga de firmware en el mikrotik. Esto puede tardar hasta 3 minutos.
  • 🔄 Actualizar Firmware: Instala el firmware que se cargó en el mikrotik con el botón "Enviar Firmware".
  • 🌐 Ping Internet: Permite realizar ping hacia internet ingresando una IP o URL sin http. Ej: 8.8.8.8, gob.cl. Para ver el resultado se debe generar un nuevo reporte.
  • 📡 Ping SBC y aprov: Permite realizar un ping hacia el SBC de la zonal y además realiza un ping hacia el aprovisionador IPBXV.
  • ⚙️ Setear Option43 Unifi: Corrige el valor del Option43, para que así la antena Unifi llegue al Controller. OST alerta con error si esta con un valor incorrecto.
  • 🔌 Reinicio: Reinicia el equipo Mikrotik.

GUÍA VISUAL DE COMANDOS DE RED (CMD)

Herramientas de diagnóstico de conectividad, lentitud y pérdida de paquetes
  • 📶
    ping 8.8.8.8 -t
    Envía paquetes sin parar para ver microcortes y estabilidad general.
  • ⏱️
    ping -n 100 8.8.8.8
    Envía exactamente 100 paquetes y da un porcentaje exacto de pérdidas.
  • 🗺️
    tracert 8.8.8.8
    Muestra el camino y los saltos que da la conexión hasta llegar al destino.
  • 🎯
    pathping 8.8.8.8
    Muestra en qué salto de red exacto se están perdiendo los paquetes.
  • 📡
    netsh wlan show interfaces
    Muestra calidad de la señal Wi-Fi (dBm) y velocidad actual de enlace.
  • 📦
    winget install Ookla.Speedtest
    Instala la utilidad oficial de Ookla para medir velocidad desde el CMD.
  • 🚀
    speedtest
    Mide bajada, subida, latencia y pérdida de paquetes. Escribe 'YES' la primera vez que lo ejecutes.
  • 💻
    ipconfig /all
    Muestra toda la configuración de red (IP, puerta de enlace y servidores DNS).
  • 🔍
    nslookup google.com
    Verifica si los servidores DNS están respondiendo de forma adecuada.
  • 📊
    netstat -e
    Muestra estadísticas recibidas, ideal para ver errores de transmisión de datos.
  • 🧹
    ipconfig /flushdns
    Borra la caché de DNS si hay problemas al cargar o resolver páginas.

AYUDA MEMORIA / CONSEJOS ÚTILES

  • Ctrl + C: Detener cualquier prueba en curso (como el ping continuo) y ver el resumen final.
  • Probar con tu Gateway (ej. ping 192.168.1.1) para saber si la falla es interna (Wi-Fi/router) o externa (Internet).
  • Guardar registro: Agrega '> red.txt' al final de cualquier comando para guardar los resultados en un archivo.
  • Ejecutar como Administrador si algún comando da error o deniega el acceso.

PORT FORWARDING (Redirección de Puertos)

Permite redirigir puertos de una IP pública a una IP privada (LAN) en la ONT.

⚠️

LÍMITES: Zhone (Máx 8 reglas) / Fiberhome (Máx 5 reglas).

📝 PASO A PASO EN OST

1
Seleccionar ONT -> Ir a Acciones -> Clic en [Port Forwarding].
2
Presionar en la flecha de [Agregar] para desplegar el formulario.
3
Completar los campos (ver detalle abajo).
4
Hacer clic en [Agregar Temporalmente]. Repetir si hay más reglas.
5
Al finalizar, presionar [Agregar] (Guardar) y confirmar con OK en el mensaje de advertencia.

📋 CAMPOS DEL FORMULARIO

NameNombre de la regla (ej: camara1).
Source Port Start/EndRango público (1 al 65535). Si es 1 solo puerto, repetir el número en ambos.
Destination IP AddressAsignar desde 192.168.1.220 hasta 192.168.1.227.
Destination Port Start/EndRango privado. Se recomienda usar el mismo puerto que el Source.
💻 DATOS PARA EL CLIENTE
El cliente DEBE configurar su equipo con:
• Puerta de enlace: 192.168.1.254
• Máscara de subred: 255.255.255.0
• IP asignada: (La definida en el paso anterior).

📌 EJEMPLOS

1 Puerto (Cámara 5000):
Source Start: 5000 / Source End: 5000
Dest Start: 5000 / Dest End: 5000

Rango (5000 al 5020):
Source Start: 5000 / Source End: 5020
*El cliente debe configurar el mismo rango en su equipo.

🔄 OTRAS ACCIONES

  • Aplicar Reglas por Defecto: Clic en `[Aplicar Reglas Por Defecto]` -> `[Aplicar]` -> Confirmar con `OK`.
  • Eliminar una regla: Marcar la casilla de la regla -> `[Eliminar]` -> Confirmar con `Continuar`.
